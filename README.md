# qrlogosvg

 Un pequeño script que recibe 3 parámetros: ruta de un logo en formato svg, un texto o url, y la ruta del archivo.svg a generar.
 
 Este script genera un codigo qr que tiene en el medio el logo especificado como primer parámetro.

 confirmado que corre con: python 3.13.5
 
 dependencias: qrcode 8.2
